# Retail-Sales-Excel-Data-Analysis
Retail Sales Excel Data Analysis Project

Overview

A complete Excel data-analysis project built around a 5,000-row synthetic retail dataset.

Deliverables

Raw Data: untouched transaction-level dataset

Working: SUMIFS, COUNTIFS, AVERAGEIFS, monthly trend and discount diagnostics

Summary: KPI dashboard, five business-question summaries, charts and findings

README: workbook documentation

Business Questions

Which category drives sales and profit?

Which region performs best?

What is the monthly sales trend?

Which customer segment is most profitable?

How does discounting affect profit margin?

Tools

Microsoft Excel / Google Sheets

Notes

The dataset is synthetic and designed for portfolio/interview practice. The five summary sections are formula-driven PivotTable-style views so the calculations remain transparent and refresh automatically.
